# Model Thyself · films

Six films from the first Model Thyself edition by Russell Foltz-Smith / Works on Becoming.

[Enter the worlds and film gallery](https://un1crom.github.io/worksonbecoming/model-thyself/review.html).

The release contains the complete Accelerating Harmonized Loop, Slow Build / Reverb Loop, and an original wordless sound landscape, each in horizontal and vertical form. These are the approved first-edition 12 fps animatics, preserved without recutting or re-encoding.

The browser experience, audio, contact sheets, and editorial notes live on the Works on Becoming site. Later refinements will form a separate edition, modelled_thyself.
